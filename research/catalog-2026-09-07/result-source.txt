pi-terminal-mux 0.4.1: `src/backends/tmux.ts` (full file, 3124 bytes) is the ONLY package here that
issues real tmux commands: `createSplit()` runs `tmux split-window -d [-h|-v] [-b] -t <fromSurface>

live-tested "unchanged active pane" requirement, addressed by explicit pane_id. `send()` uses
`send-keys -l <cmd>` + Enter; `sendEscape()` sends Escape (interrupt, not kill); `close()` runs
`tmux kill-pane -t <surface>` — an IMMEDIATE, unconditional kill with no grace/drain/confirm logic
in this file. Not depended on by either subagent package inspected this pass.
CONCLUSION 1: Neither re-inspected subagent package creates real tmux panes; only pi-terminal-mux
0.4.1 has proven `split-window -d`/`kill-pane` primitives, and it is a bare library with no
dispatcher, no lifecycle policy, no completion/steering logic.
